# CS2Stats 1.4.0 更新说明

发布日期：2026-11-25

## 一句话总结

CS2Stats.exe 的 GUI 按手绘草图重构为 HLTV 深色主题（近黑底 + 橙色强调 + 白色正文），
两个标签页的信息层级重新梳理，只改 UI 层，解析与数据层零改动。

## 更新内容

### GUI 深色 HLTV 主题

- 整体深色：窗口底色近黑（#14161b），卡片深灰（#1d2027），输入框（#23262f），
  正文近白，橙色（#f26a21）只用于主按钮与关键状态。
- 颜色/字号全部收敛到 `cs2stats/gui.py` 顶部的 design token，改主题只动一处。
- 字体保持大字号（正文 15、标题 26 粗体、主按钮 17 粗体），2K 屏 150% 缩放下清晰可读。

### 自动监听页（按草图重排）

自上而下：大标题 → 你的游戏 ID（高亮主角行）→ 主操作按钮（开始监听 / 停止监听 /
打开最近报告）→ 状态行 → 「使用流程」卡片（两步说明）→「高级设置」卡片
（demo 录像文件夹 / 报告保存到 / 计分板校验文件 + 配置 .cfg 按钮、stats.cfg
就绪状态、GOTV 设置入口、找不到校验文件也照常生成开关）。

### 手动解析页（按草图简化）

单卡片：你的游戏 ID → Demo 文件（.dem）→ 计分板校验文件（可留空，附口径提示），
下方一个大号橙色「开始生成报告」。页面底部保留精确层口径说明
（哪些字段精确、哪些是推断/近似）。

### 相对草图的取舍（平台惯例优先）

- 草图未画状态行/进度条：保留（监听与解析必须有反馈），放在按钮下方。
- 草图未画「生成后自动打开」：保留在按钮行右侧（高频开关）。
- 草图把 GOTV 配置入口去掉了：stats.cfg 按草图内联为「配置 .cfg」按钮 +
  就绪状态；原 GOTV 弹窗（tv_enable 等）保留为高级设置卡片里的「GOTV 设置…」，
  功能不丢。
- 草图中元素间距不均/未对齐：统一 8px 栅格（8/12/16/22），三行表单项同列对齐。
