# CS2Stats 1.2.0 更新说明

发布日期：2026-11-23

## 修复的问题

1. **「高级 / GOTV 配置」按钮点了没反应**
   之前点击后程序内部直接报错（少了一个组件导入），所以看起来毫无反应。
   现在点击会正常弹出配置窗口，保存的设置也会被自动监听流程读取。

2. **cfg 文件名统一为 `stats.cfg`**
   旧版本生成的 `stat.cfg` / `stat_cs2stats.cfg` 会在确认是程序自己生成的
   内容后自动清理，不会再有旧文件残留。开图前在 CS2 控制台执行：
   `exec stats`，然后 `map de_mirage`（或你要玩的图）。

## 新功能与改进

3. **击杀矩阵（Kill Matrix）恢复并升级**
   - 之前遇到事件归因错乱的 demo 会整块隐藏矩阵；现在改为**逐回合与
     计分板核对**，核对通过的回合正常进矩阵，不通过的回合号会明确列出来
     （例如你的 Mirage 那场：覆盖 8/14 回合，排除 5/6/7/10/12/13）。
   - 摔死/烧死/自杀不再被丢弃，单独归入「环境」行/列。
   - 新增「击杀视角 / 死亡视角」切换，以及 All / First kills / AWP / 手枪
     四种筛选，颜色越深表示次数越多。

4. **Rating 换成公开流传的 Rating 2.0 近似公式，并新增「Rating 分解」表**
   - 每个人的 KPR / DPR / KAST / Impact / ADR / Swing / econ Δ 分项列出，
     方便和 HLTV 的数据一项一项对照（总分仍是近似值，报告里有标注）。
   - KAST 的「补枪」判定补上了：死亡后 5 秒内队友完成击杀算 traded，
     但只在核对一致的回合计入。

5. **数据异常会明说，不再静默**
   比分和≠回合数、死亡数比击杀还少、选手缺快照等自相矛盾的情况，
   现在会在报告顶部橙色「解析提示」横幅里列出来。

6. **解析缓存**
   同一个 demo 第二次生成报告几乎瞬间完成（实测约 2.4 秒 → 0.04 秒）。
   缓存在程序根目录 `cache\`，可以整个删掉；demo 文件变了会自动重新解析。

7. **界面换新**
   - 主程序改为 HLTV 风格的深色界面，字体更大，主按钮是醒目的橙色。
   - 报告头部重做：渐变地图大标题、发光比分、MVP 金卡。

## 不变的东西

- K/D/A/ADR 依然只认计分板属性（最可靠的那一层），并且通过了
  40 项 fixture 校验。
- 报告仍然是单文件 HTML，离线可看，不需要联网。
- 旧版本生成的历史报告不受影响，可以正常打开。

## 已知限制

- 事件层归因错乱的 demo（例如 bot 接管过的对局），Kill Matrix 只覆盖
  核对一致的回合；KAST 的 traded 也只在这些回合计入。这是有意保守，
  宁可少显示也不显示错误数据。
- 报告只针对单张地图，不做跨图汇总。
