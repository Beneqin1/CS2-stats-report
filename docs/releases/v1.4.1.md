# CS2Stats 1.4.1 更新说明

发布日期：2026-11-25

## 一句话总结

HTML 报告的六维雷达图升级为固定职业基准刻度 + "爆表"特效：某项数据超过外环
（2× 职业均值基准）时顶点真实冲出网格，金色霓虹发光并在外侧标注大数字 + "best"，
普通数据保持原有干净 HLTV 风格。只改报告呈现层，解析与数据契约零改动。

## 更新内容

### 固定刻度（不再随数据自适应）

- 每轴刻度固定：中环 = 职业均值基准（`RADAR_PRO_AVG`），外环 = 2× 基准。
  刻度与数据解耦，不同报告之间可直接对比。
- 基准口径（`cs2stats/config.py`）：KPR 0.72 / Rating 1.06 / Impact 1.30 /
  ADR 78 / KAST 72 / Surviving 36。Impact 基准按本项目公式口径校准
  （本项目 Impact 含首杀/多杀加成，比 HLTV 口径高约 0.2，用 1.10 会让
  普通好局也爆表，破坏效果稀缺性）。

### "爆表"视觉

- 顶点超出外环：ECharts 对超 max 的值线性外推绘制（不压平、不裁剪），
  顶点是真实地冲出网格。
- 爆表时玩家多边形切换为金色霓虹（#ffe9a8，3px，强外发光），该顶点外侧
  叠加三行标注：轴名（中英）+ 26px 斜体大数字 + 小斜体 "best"；
  未爆表轴保持原小字数值轴名。
- 爆表标签由 HTML 覆盖层绘制（轴名并入标签组），与 ECharts 轴名物理上
  不可能重叠；T / CT / 全场视图切换时标签层正确重建。
- 极度超标（峰值 > 1.7× 外环）时网格物理等比收缩（半径 = 78/峰值 %），
  顶点和标注始终留在画布内；数值→半径映射全程线性，不夸大任何数值。

## 刻度与溢出逻辑

- 轴上限：`RADAR_MAX = 2 × RADAR_PRO_AVG`，固定，不随数据增长。
- 判定：`value > max` 即爆表（数据层 `report_data.py` 输出 `burst` 标志，
  渲染端按 ratio 重算校验）。
- 溢出映射：顶点半径 = value/max × 外环半径，线性外推；峰值 ≤1.7 时网格
  半径 46%，>1.7 时收缩为 78/峰值 %，最差不低于 16%。
- 全场平均多边形不参与爆表判定（爆表只针对分析对象）。

## 验证

- 回归三件套通过：compileall、15 个 unittest、mirage fixture 精确层校验
  （10 选手 × 4 字段全一致）。
- 三种状态截图核验：普通态（6 轴小字数值，无发光）/ 自然爆表态
  （mirage demo 真实数据 KPR 1.57、Rating 2.35、Impact 3.25 爆表，
  标注方向与间隙正确）/ 极端爆表态（合成 Impact 6.00 = 2.3× 外环，
  网格收缩后顶点与标注均在画布内）。
- T / CT 视图切换核验：各切片独立爆表判定（如 T 侧 ADR 157.7 爆表），
  覆盖层随切换正确重建。

## 兼容性

- 仅报告模板（`templates/report.html.j2`）+ 雷达刻度常量（`config.py`）
  + 数据层雷达载荷（`report_data.py` 增加 baseline/burst 字段）改动，
  历史 demo 重新生成的报告自动获得新样式，数据口径不变。
