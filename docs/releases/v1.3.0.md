# CS2Stats 1.3.0 更新说明

发布日期：2026-11-23

## 界面

1. **程序界面换回亮色系**
   白底、深灰文字、橙色强调按钮，整体更清爽（Linear/Notion 风格）。
   配色全部集中在代码里的 design token，不再有残留的暗色写死值。
   HTML 报告保持原来的 HLTV 深色风格，没有动。

## 数据更全、更透明

2. **Match stats 表格新增 5 列**（All / T / CT 都有）
   - KPR（每回合击杀）、HS%（爆头率）
   - 首死（每回合第一个阵亡的次数）、FK%（首杀对决成功率）
   - MVP 次数（本地 demo 没有官方 MVP 事件，按规则近似：每回合胜方
     击杀+0.45×助攻最高者，报告里标注"近似"）
   - 首杀/首死现在用同一把尺子（计分板每回合首次增量）：
     全场首杀数 + 首死数恒等于回合数，不会再出现"只有首杀没有首死"。

3. **报告顶部新增「数据可信度」标签行**
   一眼看清这场数据的成色：是否检测到玩家接管 bot、击杀矩阵核对
   覆盖了多少回合、事件层是否降级。
   检测到接管时，接管回合的击杀事件会被标记清洗，不混入矩阵/高光/
   风格统计，并在解析提示里说明清洗了多少条。

4. **击杀矩阵新增「残局 1vX」筛选**
   只看自己只剩 1 人、对面至少 2 人时的对位击杀；鼠标悬停格子会显示
   双向次数和占比。

## 新板块（按报告顺序）

5. **打法风格指纹 · Style DNA（实验）**
   不打分数，告诉你"你是什么类型的选手"：侵略 / 存活 / 后段发力 /
   道具 / 前期参与 / 游走六维雷达图，自动归类风格原型（突破手 /
   自由人 / 辅助 / 狙击核心 / Anchor），并给出 Top 3 相似职业选手
   （s1mple、ropz、donk 等 8 人预设画像）与一句话总结。
   指标口径全部写在 `docs/style_dna.md`；画像目前是手工预设值，
   后续会用真实 demo 校准，相似度仅供娱乐参考。

6. **教练建议 · Coach**
   12 条规则按阈值触发，不做泛泛的"多练枪"：每条都锚定本场数据
   （例如"手枪局 2 局 0 杀，只有全场 KPR 的 0%"），带严重度排序、
   具体练习方向和可展开的数据依据。全部达标时会明确告诉你
   "本场未触发任何改进建议"。

7. **高光回合 · 一键回放（报告末尾）**
   自动识别精彩回合：残局翻盘（1vX 获胜）、单回合 4/5 杀、
   8 秒内 3 杀、ECO 翻盘、首杀后 15 秒速胜。
   每张卡片有「复制回放指令」按钮：在 CS2 控制台粘贴
   `playdemo "..."; demo_goto <tick>` 即可跳到该回合开头观看。
   顶部还有回合时间线条，按胜方着色、高光回合有金框标记。

## 底层修复

8. kill_feed 的回合内时间之前把冻结时间（freeze time）也算进去了，
   导致"回合前 20 秒"这类统计整体偏移约 21.5 秒；现已修正为从
   freeze 结束起算。

## 质量保障

- 新增 15 个单元测试（bot 接管清洗 / 高光识别 / 教练规则阈值），
  运行方式：`.\.venv\Scripts\python.exe -m unittest discover -s tests -v`
- 精确字段基线不变：用户 Mirage fixture 10 人 × 4 项 = 40 项校验
  全部通过（K/D/A/ADR 与游戏内计分板逐项一致）。
- 解析缓存版本号已升级到 v5，旧缓存自动失效，无需手动清理。
