# CS2Stats 1.3.2 更新说明

发布日期：2026-11-24

## 界面与易用性

- **整体字体放大**：正文 13→15、标题 26→30、主按钮 15→17、提示 11→13；
  窗口默认 1180×920（最小 1040×840）。
- **小白友好文案**：
  - "目标选手" → "你的游戏 ID"；"计分板 fixture" → "计分板校验文件（可留空）"；
  - 自动监听页顶部新增四步流程说明（exec stats → 开始监听 → 打一局 → 自动出报告）；
  - 标签页改为"自动监听（推荐）/ 手动解析 Demo"。
- **默认目录补全**：demo 录像文件夹默认自动定位 `game\csgo\replays`（并记忆到
  settings.json）；报告输出固定展示为 exe 同级 `output\`；手动选择 demo 的文件
  对话框默认打开 replays 目录。

## 报告（HTML）样式统一

- 各板块对齐雷达图面板的卡片语言：Style DNA 拆为"风格雷达 / 相似度·原型与职业
  对标"两张子卡片；Kill Matrix 面板与统计表同宽（1380px）；高光卡与教练卡统一
  内边距（14px 16px）与圆角；卡片网格间距统一为 16–18px。

## 代码精简

- 删除无调用的 `app.find_default_output`、未使用的 `DEFAULT_LOOKBACK`、
  重复的 `mkdir`、冗余 tkinter import、模板里重复的 CSS 属性。

## 打包

- **zip 平铺结构**：解压后第一层就是 `CS2Stats.exe`（连同 `_internal\`、
  `fixtures\`、`README.txt` 等），不再多套一层 CS2Stats 文件夹。
- 首次运行产物（`output\`、`stats.cfg`、`settings.json`、`cache\`）均生成在
  exe 同级，随文件夹整体可携带。

## 质量

- 15 个单元测试通过；mirage fixture 10 人 × 4 项（K/D/A/ADR）校验一致；
  监听竞态仿真与 cbble 截断检测回归通过（1.3.1 修复未受影响）。
