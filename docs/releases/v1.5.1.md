# CS2Stats v1.5.1

## 更新内容

- K-D 恢复短横线，例如 22-7。
- Match Stats 取消内部 1120px 限宽，表格填满所在面板，与其他报告模块对齐；正文和玩家名增至 18px，数值及数值列标题居中，保留细竖线。
- 补上 Swing：事件数据可靠时使用原启发式 WPA；不可靠时使用计分板估算 `(4×(K−D)+A)/回合数`，明确标注“非 WPA / 非 HLTV”，保留警告和 tooltip。此公式为展示估算，不宣称真实回合胜率变化。
- Style DNA 采用 Player performance 相同的金色雷达面板、红色虚线参考画像、对比条轨道与填充样式，扩大雷达和文字可读空间。
- 职业画像相似度从前三名归一化占比改为独立 `100×exp(-4×RMSE)`，不再强制合计 100%；明确列出最相似选手。RMSE 为可用归一化维度的均方根距离；参数固定，不按单场拉开差距。画像仍是预设参考，不能解读为职业表现水平或概率。
- 校验结果（含未校验警告）和解析提示整体移到页面最后，提示内容完整保留。

## 验证

- compileall 通过；36 项单测通过，其中新增 3 项覆盖独立画像相似度、估算 Swing 来源与正负值。
- 无缓存 Mirage demo → HTML：14 正式回合、10 人，40 项 K/D/A/ADR fixture 校验 verified。
- 浏览器实际加载报告，DOM 确认 K-D 格式、Swing 数值、Style DNA 最相似选手、末尾审计信息。
- 示例 Beneqin1 Swing +4.43%；源为计分板估算，不是 WPA。测试中的预设画像自匹配为 100%。
- 最终包内 CS2Stats.exe 无缓存冒烟通过：退出码 0，HTML 包含 v1.5.1、40 项校验、估算 Swing、最相似选手和末尾审计区；ZIP 根目录包含 exe，未包含 output 运行目录。
- 当前模型不能读取截图像素；没有宣称已完成主观视觉审美验收。

## 复盘

改动局限于报告渲染、近似算法、测试及必要发布文件，未改解析器、精确统计、依赖或 GUI。Swing fallback 是用户本轮明确允许的估算，来源和局限可见，没有静默冒充 WPA。完整 demo 到 HTML 已通过；最终打包 exe 另作冒烟验证。

## 流程自省

旧版“Swing 不可靠就隐藏”的记忆已更新为本轮允许的明确标注估算；雷达 2× 旧规则仍保留归档说明。建议今后用“来源标签 + 口径公式 + 缺失处理”统一描述近似指标，减少“补上数据”与“保持精确”之间的歧义，由用户决定是否采纳。
