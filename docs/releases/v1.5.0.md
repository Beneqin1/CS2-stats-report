# CS2Stats v1.5.0 更新记录与验收状态

## 改动

- Match Stats：Player 后严格保留 K-D、Swing、ADR、HS%、KAST、Rating 六列；队伍大写、比分右对齐，数值右对齐，增加 1px 低对比竖线，正文 16px。
- Rating 分解：保留 +/-、K/D、KPR、K(HS)、D、A、首杀、首死、FK%、MVP、HS%，补充 DPR、APR、ADR、KAST、Impact 与原始 Rating，横向滚动保留可读性。
- Rating 超过 2.0 时采用 `2 + (原始值 - 2) × 0.85`；原始值仍可核对。
- 雷达固定外环为职业参考值的 1.5 倍，2/3 半径环为参考值；超出按真实值线性外推。画布按峰值预留空间，强化金色光晕和 32px best 标注。参考基准是预设值，非职业数据库统计结论。
- 新增独立 swing.py：经济、存活人数、阵营先验、下包、剩余时间的启发式胜率模型，逐事件计算个人 WPA。按正式回合数平均后输出百分点，不按单场截图调整比例。
- 不使用 awpy win-prob extra：它需要额外依赖与在线下载模型，不符合当前离线及依赖约束。
- 事件层、经济或 bomb 输入不可靠时隐藏 Swing 并显示明确警告，不以 K/D 代理冒充 WPA。
