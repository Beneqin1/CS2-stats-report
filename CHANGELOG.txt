CS2 数据报告 1.2.0
======================================================================

本版改动
----------------------------------------------------------------------
1. Bug 修复
   - 修复主界面“高级 / GOTV 配置”按钮点击无响应（Toplevel 未导入导致
     回调直接抛错）；弹窗现在正常打开，保存的配置会被监听流程读取。
   - 自动注入 CS2 的 cfg 统一为 stats.cfg（控制台执行 exec stats）；
     旧版 stat.cfg / stat_cs2stats.cfg 在确认是本程序生成内容后自动清理，
     避免旧文件残留。

2. Kill Matrix 重做
   - 以 SteamID 为关联主键，玩家改名/空名不再影响归属。
   - 每个正式回合与计分板每回合 K/D 差分逐人核对，仅保留完全一致的
     回合进入矩阵；排除回合号与覆盖度直接写在报告里。
   - attacker 为空的死亡（摔死/烧死/自杀）归入“环境”行/列，不再丢弃。
   - 新增“击杀视角 / 死亡视角”切换与 All / First kills / AWP / 手枪
     四种范围，热力颜色深浅体现次数。

3. Rating 2.0 近似公式 + 分解表
   - Rating = 0.0073×KAST% + 0.3591×KPR − 0.5329×DPR
              + 0.2372×Impact + 0.0032×ADR + 0.1587。
   - Impact = 2.13×KPR + 0.42×APR − 0.41 + 首杀/多杀回合加权。
   - KAST 补枪判定：死亡后 5 秒内队友完成击杀算 traded，仅计入核对
     一致的回合。
   - 报告新增“Rating 分解”表：KPR/DPR/KAST/Impact/ADR/Swing/econ Δ
     各项独立列出，便于与 HLTV 交叉核对。

4. 数据精准度
   - 新增自洽性校验：比分和=回合数、死亡数≥击杀数、每回合差分和=总计、
     缺快照回合等，异常会进入报告顶部的“解析提示”横幅，不再静默。
   - 新增解析结果缓存（cache\，按 demo SHA-256 + 解析器版本守卫）：
     同一 demo 二次解析从约 2.4 秒降到约 0.04 秒；
     --no-cache 跳过，--clear-cache 清空。

5. 界面
   - GUI 改为 HLTV 风格深色主题（深底 + 橙色主按钮），全局字号上调，
     窗口默认 1040×820。
   - 报告头部重做：渐变地图大标题、发光比分、MVP 金卡。

----------------------------------------------------------------------

CS2 数据报告 1.1.0
======================================================================

历史改动
----------------------------------------------------------------------
1. 首次运行生成 stat.cfg
   - 在 exe 同级生成 stat.cfg，内容为：
         tv_enable 1
         tv_autorecord 1
   - 自动定位 CS2 的 game\csgo\cfg 并复制。
   - 如果已有 stat.cfg，不覆盖，改名为 stat_cs2stats.cfg。
   - 定位失败时弹出目录选择；取消后可在主界面“配置 stat.cfg…”重试。
   - 用 exe 同级 settings.json 记录首次初始化，避免每次启动重复写入。
   - 不修改 autoexec.cfg 或 server.cfg。

2. 路径调整
   - demo 默认监听目录改为 <CS2>\game\csgo\replays。
   - 手动选择或自动定位的 replays 目录写入 settings.json。
   - 报告统一输出到 exe 同级的 output\，自动创建；文件名含地图和时间戳。

3. exe 界面
   - 全局基础字号上调；按钮、输入框、标签页高度同步增加。
   - 保留原有布局结构，只调整尺寸和间距。
   - 新增“配置 stat.cfg…”按钮和状态行。
   - 窗口默认尺寸调整为 1000×780。

4. 精简与打包
   - 删除开发期缓存、临时测试目录和未使用文件。
   - 发布包不再包含 GSI 开发记录。
   - 只保留运行所需的依赖：awpy、Jinja2、polars、demoparser2、pandas。
   - PyInstaller 使用 onedir 模式，输出 CS2Stats-1.1.0-onedir。

5. 冻结项
   - HTML 模板、CSS、图表配置、表格结构、排序、颜色、脚注位置
     本版未改动（与 1.1.0 的最后一次 HTML 版本一致）。
