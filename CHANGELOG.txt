CS2 数据报告 1.3.1
======================================================================

本版改动
----------------------------------------------------------------------
1. 修复：人机居多的对局（cbble）报告只显示 1 个回合。
   - 根因是 .dem 文件本身只录制了约 108 秒（第 1 回合完整，
     第 2 回合开打约 4 秒后录制终止），属于 GOTV 录制截断，
     并非解析漏回合；该 demo 击杀坐标完整，与地图数据无关。
   - 解析层新增截断录制检测：用 round_freeze_end 游戏状态事件
     补充核对回合表；已开打但没有结束记录的回合标记为
     still_in_progress，不计入任何统计，并在报告警告区与
     data_quality 中明确说明"录制不完整"及具体回合号/tick。
2. 修复：实时监听进入地图后立刻报"dem 无法解析"。
   - 根因是竞态：进图时 GOTV 刚创建 .dem（只有头部），地图加载
     期间文件数秒不增长，监听器误判"文件稳定"立即解析失败；
     且旧逻辑解析前就标记已处理，失败不会重试。
   - 改为解析成功后才标记已处理；不完整类错误指数退避重试
     （5s/10s/15s…最多 6 次），文件继续增长自动重置计时；
     <16KB 的 .dem 直接判定仍在创建；重试耗尽才报一次错；
     单个文件失败不再影响监听进程；fixture 不一致仍是硬错误，
     立即报告不重试。
3. 手动选择 Demo 不再强制要求 fixture。
   - 没有找到计分板 fixture 时，仍会生成报告，顶部标"未校验"，
     并在生成成功弹窗中明确提示。
   - 找到 fixture 但与本场 demo 不一致时，仍然停止生成并列出差异。
   - 命令行手动模式同步：默认允许缺少 fixture；需要强制校验时加
     --require-fixture。
   - README 与 fixtures/FIXTURE_FORMAT.txt 同步更新。
4. 解析缓存版本升级到 v6（解析逻辑变化，旧缓存自动失效）。
5. README.md 重写：特性、免责声明（Rating 近似、人机局与非现役
   地图支持情况）、快速开始、技术栈与流程图、构建步骤、Roadmap、
   MIT License。

CS2 数据报告 1.3.0
======================================================================

本版改动
----------------------------------------------------------------------
1. 数据层补全（Match stats 扩列）
   - 新增 KPR、HS%、首死、FK%（首杀成功率）、MVP 次数，全部按
     All / T / CT 切片；首杀与首死均由计分板 kills_total /
     deaths_total 的每回合首次增量推断，口径一致（首杀 + 首死
     合计恒等于回合数）。
   - 本地 GOTV demo 无 round_mvp 事件，MVP 次数为规则近似
     （胜方回合 kills + 0.45×assists 最高者），报告中标注“近似”。
   - Kill Matrix 新增“残局 1vX”范围（击杀方存活 = 1 且受害方存活
     ≥ 2 的击杀）；单元格悬停显示双向次数与占比。
   - 报告顶部新增“数据可信度”标签行：bot 接管检测（m_bControllingBot
     采样）、矩阵核对覆盖度、事件层是否降级，一目了然。
   - bot 接管清洗：检测到接管时，接管回合的击杀事件标记
     bot_controlled，不计入事件层衍生统计（矩阵/高光/Style DNA）。
   - 修复 kill_feed 时间戳把 freeze 时间计入的问题（t 现从
     freeze 结束起算）。

2. exe 界面换回亮色系
   - 深色主题回退为亮色（白底、深灰文字、橙色强调），配色集中在
     gui.py 顶部的 design token（BG/PANEL/FIELD/TEXT/MUTED/ORANGE/
     LINE），无残留暗色硬编码。HTML 报告风格保持不变。

3. 高光回合 · 一键回放（新板块，位于报告末尾）
   - 规则识别：残局翻盘（≤2 存活劣势赢下回合）、单回合 4K/5K、
     8 秒内 3 杀、ECO 翻盘（胜方装备 < 败方一半）、速胜（首杀后
     15 秒内结束）；残局/多杀仅统计逐回合核对一致的回合。
   - 每张卡片带“复制回放指令”按钮（playdemo + demo_goto tick），
     附 demo 内时刻（mm:ss）；回合时间线条按胜方着色并标记高光。

4. 打法风格指纹 · Style DNA（实验，新板块）
   - 六维特征向量：侵略 / 存活 / 后段发力 / 道具 / 前期参与 / 游走，
     口径与归一化常数见 docs/style_dna.md。
   - 风格原型分类（突破手/自由人/辅助/狙击核心/Anchor），
     Top 3 职业选手相似度（8 人预设画像，文档注明非真实 demo 解析）。
   - 六维雷达图（对比 Top1 画像）+ 相似度条形 + 一句话风格总结。

5. 教练建议引擎（新板块）
   - 12 条阈值规则（首杀胜率、首杀参与、手枪局产出、爆头率、KAST、
     阵营 DPR 失衡、被补枪占比、多杀缺失、高存活低产出、道具不足、
     残局失利、逆风局效率），每条含地图锚定数据、严重度、练习方向、
     可展开的数据依据；规则函数列表 RULES 为插件化预留接口。

6. 测试与文档
   - tests/test_v130.py：bot 接管清洗、高光识别规则、教练规则阈值
     共 15 个单元测试（unittest，零依赖）。
   - docs/style_dna.md：Style DNA 全口径文档。

校验：用户 Mirage fixture 10 人 × 4 项 = 40 checks verified 通过；
高光/Style DNA/教练板块已在本机浏览器逐项回归。

CS2 数据报告 1.2.0
======================================================================

本版改动
----------------------------------------------------------------------
1. Bug 修复
   - 修复主界面“高级 / GOTV 配置”按钮点击无响应（Toplevel 未导入导致
     回调直接抛错）；弹窗现在正常打开，保存的配置会被监听流程读取。
   - 自动注入 CS2 的 cfg 统一为 stats.cfg（控制台执行 exec stats）；
     旧版 stat.cfg / stat_cs2stats.cfg 在确认是本程序生成内容后自动清理，
     避免旧文件残留。

2. Kill Matrix 重做
   - 以 SteamID 为关联主键，玩家改名/空名不再影响归属。
   - 每个正式回合与计分板每回合 K/D 差分逐人核对，仅保留完全一致的
     回合进入矩阵；排除回合号与覆盖度直接写在报告里。
   - attacker 为空的死亡（摔死/烧死/自杀）归入“环境”行/列，不再丢弃。
   - 新增“击杀视角 / 死亡视角”切换与 All / First kills / AWP / 手枪
     四种范围，热力颜色深浅体现次数。

3. Rating 2.0 近似公式 + 分解表
   - Rating = 0.0073×KAST% + 0.3591×KPR − 0.5329×DPR
              + 0.2372×Impact + 0.0032×ADR + 0.1587。
   - Impact = 2.13×KPR + 0.42×APR − 0.41 + 首杀/多杀回合加权。
   - KAST 补枪判定：死亡后 5 秒内队友完成击杀算 traded，仅计入核对
     一致的回合。
   - 报告新增“Rating 分解”表：KPR/DPR/KAST/Impact/ADR/Swing/econ Δ
     各项独立列出，便于与 HLTV 交叉核对。

4. 数据精准度
   - 新增自洽性校验：比分和=回合数、死亡数≥击杀数、每回合差分和=总计、
     缺快照回合等，异常会进入报告顶部的“解析提示”横幅，不再静默。
   - 新增解析结果缓存（cache\，按 demo SHA-256 + 解析器版本守卫）：
     同一 demo 二次解析从约 2.4 秒降到约 0.04 秒；
     --no-cache 跳过，--clear-cache 清空。

5. 界面
   - GUI 改为 HLTV 风格深色主题（深底 + 橙色主按钮），全局字号上调，
     窗口默认 1040×820。
   - 报告头部重做：渐变地图大标题、发光比分、MVP 金卡。

CS2 数据报告 1.1.0
======================================================================

历史改动
----------------------------------------------------------------------
1. 首次运行生成 stat.cfg
   - 在 exe 同级生成 stat.cfg，内容为：
         tv_enable 1
         tv_autorecord 1
   - 自动定位 CS2 的 game\csgo\cfg 并复制。
   - 如果已有 stat.cfg，不覆盖，改名为 stat_cs2stats.cfg。
   - 定位失败时弹出目录选择；取消后可在主界面“配置 stat.cfg…”重试。
   - 用 exe 同级 settings.json 记录首次初始化，避免每次启动重复写入。
   - 不修改 autoexec.cfg 或 server.cfg。

2. 路径调整
   - demo 默认监听目录改为 <CS2>\game\csgo\replays。
   - 手动选择或自动定位的 replays 目录写入 settings.json。
   - 报告统一输出到 exe 同级的 output\，自动创建；文件名含地图和时间戳。

3. exe 界面
   - 全局基础字号上调；按钮、输入框、标签页高度同步增加。
   - 保留原有布局结构，只调整尺寸和间距。
   - 新增“配置 stat.cfg…”按钮和状态行。
   - 窗口默认尺寸调整为 1000×780。

4. 精简与打包
   - 删除开发期缓存、临时测试目录和未使用文件。
   - 发布包不再包含 GSI 开发记录。
   - 只保留运行所需的依赖：awpy、Jinja2、polars、demoparser2、pandas。
   - PyInstaller 使用 onedir 模式，输出 CS2Stats-1.1.0-onedir。

5. 冻结项
   - HTML 模板、CSS、图表配置、表格结构、排序、颜色、脚注位置
     本版未改动（与 1.1.0 的最后一次 HTML 版本一致）。
